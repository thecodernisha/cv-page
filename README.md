# cv-page
A simple and responsive CV/Resume webpage built using **HTML and CSS**.
This project was created to practice basic HTML structure, semantic HTML, CSS styling, responsive design and Git/GitHub.

## Live Project
GitHub Repository:   https://github.com/thecodernisha/cv-page
project URL:  https://roadmap.sh/projects/single-page-cv

## Features
  Clean CV/Resume layout
  Responsive design
  Semantic HTML structure
  Education section
  Skills section
  Experience section
  Contact information
  LinkedIn and GitHub profile links
  Mobile-friendly layout

## Technologies Used
  HTML5
  CSS3
  Git
  GitHub
